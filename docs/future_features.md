# Future Features

## AI Voice Booking Agent

Allow customers to call, describe their requirement, and receive a quote request — automatically logged to CRM.

## Flight Delay Awareness (Automated)

Automatically:
- Detect delays on booked arrivals
- Alert driver of updated ETA
- Send revised pickup time to client

## Dynamic Availability Calendar

Public-facing or WhatsApp-accessible calendar showing available slots — reduces back-and-forth on scheduling.

## Driver Dispatch System

Automatically:
- Assign drivers to confirmed bookings
- Optimise multi-pickup routes
- Track driver availability in real time

## Hotel Partner Dashboard

Allow hotel partners to:
- Request pickups for guests
- Track driver ETA
- Manage recurring guest transport

## Swahili AI Responder

A separate outreach message generator trained specifically for Swahili and Sheng leads, with culturally appropriate tone and phrasing.

## WhatsApp Broadcast List Intelligence

Monitor opt-in broadcast lists from partners (hotels, event organisers) for transport requests — fully compliant since recipients have opted in.
